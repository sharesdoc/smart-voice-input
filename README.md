# VoiceInput —— macOS AI 智能语音输入

常驻菜单栏的跨 App 语音输入工具：**双击 ⌘ / 自定义快捷键**说话，语音经**五引擎 ASR**识别为文字，再由**本地/在线大模型**做智能加工，自动注入当前光标处。全程可离线。

> 完整需求见 [`A-系统需求文档.md`](./A-系统需求文档.md)，设计见 [`B-系统设计文档.md`](./B-系统设计文档.md)。

## 核心优点

### 🎯 真正「说完即所得」

- **连续听写**：触发一次即可持续说、持续输入，按停顿自动断句分段，无需每句按一次键。
- **1 秒停顿默认切段**：比同类工具更跟手；0.3~5.0 秒可调，适应不同语速。
- **提示音 + 菜单栏图标**：进入听写瞬间反馈，状态一目了然（空闲/聆听/识别/整理/注入）。

### 🧠 五引擎 ASR + 四模式后处理，适配全场景

| 场景 | ASR 引擎 | 后处理模式 |
|------|----------|-----------|
| 离线最准 | 本地 Whisper (faster-whisper) — `tiny`/`base`/`small`/`medium` 四档 | `polish` 智能纠错润色（纠错别字+补标点，忠实原话） |
| Apple Silicon 极速 | 本地 MLX Whisper — Apple 原生 MLX 加速，比 CPU 快数倍 | `organize` 智能整理（去口头禅+重组语序+通顺书面句） |
| 离线极快、自带标点 | 本地 SenseVoice-Small — 非自回归，~70x 实时，中文超强 | `translate` 中英互译 |
| 在线顶级 ASR | 阿里云 Fun-ASR (paraformer-realtime-v2) — 自带 ITN+语义标点 | `raw` 纯转写（不调 LLM，最快） |
| 在线 OpenAI 兼容 | 任何兼容 `/audio/transcriptions` 的服务 | — |

五种 ASR 引擎可在设置中一键切换，本地引擎模型首次自动下载、后台预热，下次说话无需等待。

### 🛡️ 层层防幻觉，安静场景不「自说自话」

工业级噪音与幻觉过滤体系，安静环境下绝不自言自语：

1. **Whisper 层** — 内置 Silero VAD（去静音）+ 不跨窗条件 + 静音/压缩比/概率阈值三刀，过滤重复 token 死循环与 YouTube 字幕遗毒（"请不吝点赞""订阅"等）。
2. **SenseVoice 层** — 纯标点输出自动拦截（静音段常只输出一个"。"）。
3. **VAD 语音时长验证** — 识别出 N 字却没几声真语音 → 判底噪幻觉，可针对 1/2/3 字分别设最少语音时长门槛，4 字以上不限。
4. **强制过滤黑名单** — 用户可配置短语黑名单，忽略大小写、空白和标点匹配，过滤引擎顽固幻觉（如 "Yeah""嗯嗯"）。
5. **内容缩水护栏** — LLM 整理结果异常偏短（原文≥12 字但结果不足 50%）→ 判定 LLM 抽风，自动降级用原文，不丢信息。

### 🌐 大模型智能加工：离线在线任选

- **本地 Ollama**：配合 `qwen2.5:7b` 等模型，全程无网可用、零延迟顾虑、零隐私泄漏。
- **在线 OpenAI 兼容**：支持任何兼容接口（OpenAI / DeepSeek / 通义千问 / 豆包等）。
- **思考模型控制**：自动关闭 reasoning/thinking（减少延迟和改写），并兜底清理 `<think>` 泄露内容。
- **低温度 + 输出上限**：默认少改写、不续写、不编造，忠实于原话。
- **自定义系统提示词**：高级用户可覆盖内置提示词模板。

### 🎛️ 原生 Cocoa 设置面板，所有参数一站管理

分类布局 + 下拉/开关为主，包含：通用、噪音过滤、语音识别、听写交互、智能断句、LLM 后处理、在线模型、降噪、SenseVoice 等。保存/取消/恢复默认三按钮。API Key 存 **macOS 钥匙串**，不写入配置文件。

### 🧹 神经网络实时降噪 (DeepFilterNet3)

在 VAD 之前对音频做 ONNX 实时降噪，清理环境噪声后再做人声检测和识别。可调降噪强度、干湿混合比。加载失败或处理异常自动直通原始音频，不阻断录音链路。

### 🔒 安全设计

- **API Key 不进明文**：在线 Key 存入 macOS 钥匙串（`keyring`），环境变量 `VOICEINPUT_ONLINE_API_KEY` 优先（便于 CI）。
- **剪贴板恢复**：粘贴注入后恢复用户原剪贴板内容，且有 `changeCount` 守卫——若用户在注入期间复制了新内容，绝不覆盖。
- **辅助功能权限检测**：启动时自检权限，无权限时弹出系统设置引导授权。
- **崩溃恢复**：音频设备路由切换（如插拔耳机）导致 PortAudio 缓存失效时，自动重新枚举设备重试。

### 🏗️ 架构清晰，可测试性强

```
双击⌘/自定义热键(hotkey) → 降噪(denoise) → 录音(audio) → VAD 切段
   → ASR(asr: 5引擎) → 原始文本
   → LLM 加工(llm: ollama/online) → 会话安全注入(injector)
   → 状态贯穿(state) → 菜单栏(app)
```

- **纯逻辑模块**（config / state / session / pipeline / llm / hotkey 判定）零 macOS 依赖，可在任意平台单测。
- **GUI / 音频 / ASR / 注入**为懒加载薄封装。
- **278 个单元测试**覆盖核心安全逻辑（噪音过滤、内容缩水护栏、强制过滤、VAD、双击检测、自定义热键、LLM 降级、配置序列化等）。

### 🌍 完整中英文双语界面

菜单、状态、设置面板、提示弹窗全部中英双语，一键切换，即时生效，无需重启。

### 📦 打包为独立 .app

通过 `py2app` 打包为 macOS 原生 `.app`（`LSUIElement` 菜单栏应用，无 Dock 图标），Apple Silicon 与 Intel 双架构兼容。

## 快速开始

```bash
# 1) 安装全部依赖（含 5 个 ASR 引擎；conda base 环境）
./install -i

# 2) 校验（py_compile + 单元测试，无需 GUI/麦克风）
./install -b

# 3) 启动菜单栏应用（nohup 后台）
./install -s            # 停止 ./install -k；重启 ./install -r
```

首次启动需在「系统设置 → 隐私与安全性」授予：
- **麦克风**（录音）
- **辅助功能** 与 **输入监控**（全局热键 + 模拟键盘注入）

## 使用

1. 启动后菜单栏出现 🎙️ 图标。
2. 在任意输入框中**双击 Command 键**（或自定义快捷键）进入连续听写。
3. 说话，停顿约 1 秒自动成段并输入；继续说继续输入；再次触发快捷键退出听写。
4. 点击图标 →「**系统配置…**」打开统一设置页（分类布局 + 保存/恢复默认）。

## 配置

全部设置集中在菜单「**系统配置…**」原生 Cocoa 窗口中。
配置文件：`~/Library/Application Support/VoiceInput/config.json`；API Key 存于 **macOS 钥匙串**，不写入配置文件。

| 项 | 默认 | 说明 |
|----|------|------|
| 语音识别引擎 | 本地 Whisper (small) | 5 引擎可选：Whisper / MLX Whisper / SenseVoice / Fun-ASR / 在线 |
| 后处理模式 | polish | 纯转写 / 智能纠错润色 / 智能整理 / 翻译 |
| 大模型引擎 | 本地 Ollama | 本地 Ollama / 在线 / 关闭 |
| Ollama 模型 | qwen2.5:7b-instruct-q4_K_M | 未安装时提示 `ollama pull` 命令 |
| 加工参数 | 温度=0 / 关闭思考 | 默认少改写原话、限制输出长度、自动清理 thinking 内容 |
| 停顿秒数 | 1.0 | 静音多久判定一句说完（支持 0.3~5.0s，预设 6 档+自定义） |
| 语言 | 中文 | 中文 / 英文（界面 + 识别同时切换） |
| VAD 软封顶 | 180s / 360s | 长段逐步放宽静音要求就近切段，防内存膨胀 |
| 噪音过滤 | 开 | 底噪幻觉拦截（1/2/3 字分设语音时长门槛） |
| 强制过滤短语 | "我,我的,Yeah…" | ASR 顽固幻觉黑名单（大小写/标点不敏感） |
| 神经网络降噪 | 关 | DeepFilterNet3 ONNX 实时降噪（可调强度/干湿比） |
| 热键触发 | 双击 ⌘ | 双击 Command / 自定义组合键 |
| 注入方式 | 粘贴 | 剪贴板 ⌘V（自动恢复）/ 键盘直输 Unicode |
| 开机自启 | 关 | 登录项自动启动 |

## 技术架构

| 层 | 技术 | 说明 |
|----|------|------|
| GUI | rumps + PyObjC (Cocoa) | macOS 原生菜单栏应用 + 分类设置面板 |
| 热键 | pynput (Quartz CGEvent) | 全局键盘监听，双击 ⌘ / 自定义组合键 |
| 音频 | sounddevice (PortAudio) | 16kHz 单声道采集，回调式流式处理 |
| 降噪 | DeepFilterNet3 (ONNX) | 神经网络实时降噪，异常自动直通 |
| ASR | faster-whisper / mlx-whisper / SenseVoice / DashScope / OpenAI | 五引擎可切换 |
| LLM | Ollama (本地) / OpenAI 兼容 (在线) | 纠错/润色/整理/翻译四模式 |
| 注入 | Quartz CGEvent + AppKit NSPasteboard | ⌘V 粘贴（自动恢复剪贴板）/ 键盘直输 |
| 安全 | macOS Keychain (keyring) | API Key 不进明文配置 |
| 打包 | py2app | 独立 .app，LSUIElement 无 Dock 图标 |
| 测试 | pytest (278 cases) | 纯逻辑模块零 macOS 依赖，可跨平台单测 |
